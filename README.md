# Taskflow — список задач

Небольшое адаптивное To-Do приложение на React + Vite.

## Возможности
- Добавление задач
- Отметка выполнения и возврат в активные
- Удаление задач
- Фильтры: все / активные / выполненные
- Автоматическое сохранение в `localStorage`
- Адаптивный интерфейс для мобильных устройств

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

Готовая версия сайта появится в папке `dist`.

## Публикация

### GitHub
1. Создайте новый публичный репозиторий на GitHub, например `taskflow-todo`.
2. Загрузите в него файлы проекта (содержимое этой папки, без `node_modules`).

### Vercel
1. Войдите на https://vercel.com через GitHub.
2. Нажмите **Add New → Project** и импортируйте `taskflow-todo`.
3. Framework Preset: **Vite**. Build Command: `npm run build`. Output Directory: `dist`.
4. Нажмите **Deploy**. Vercel выдаст публичную ссылку на сайт.

## Использованные технологии
- React — интерфейс и управление состоянием
- Vite — сборка и локальная разработка
- CSS — адаптивная стилизация
- Browser LocalStorage — сохранение задач между перезагрузками
